# Global Trade | Tariff & Compliance Intelligence

### Python Analytics • International Trade Compliance • Strategic Decision Support

**Turning global trade data into actionable business intelligence.**

This portfolio project demonstrates how Python can support international trade compliance, tariff exposure analysis, and data-driven decision-making.

Using synthetic import transactions and illustrative tariff scenarios, the analysis identifies potential duty exposure, prioritizes compliance reviews, and communicates financial implications through executive dashboards.

The project combines two analytical perspectives:

- **Tariff & Compliance Intelligence (2025–2026):** Import transaction screening, Section 201/232/301 scenario modeling, and compliance review prioritization.
- **Global Trade Trends (2022–2024):** Import/export patterns, trade balances, and country-level comparisons.

**Core skills demonstrated:** Python • pandas • Data Validation • Trade Remedy Screening • Financial Modeling • Executive Reporting
